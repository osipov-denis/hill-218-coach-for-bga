# Privacy Policy

Hill 218 Coach for BGA is a read-only browser extension beta.

## Data Collection

The extension does not collect, store, sell, or transmit personal data.

## Network Access

The extension does not make external network requests. It only reads visible page content already present in the active Board Game Arena tab.

## Page Access

The extension runs on `boardgamearena.com` pages so it can read visible Battle for Hill 218 game logs and counters.

## Gameplay

The extension does not click game controls, submit moves, automate gameplay, or use hidden Board Game Arena APIs.

## Diagnostics

The extension includes copy buttons so a tester can manually copy visible diagnostics and send them to the developer if they choose.

## Contact

For beta testing, contact the person who shared the repository or ZIP with you.
